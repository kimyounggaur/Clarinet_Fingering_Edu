# 클라리넷 운지 트레이너

표준 보엠식 클라리넷의 기보음 E3–A6 운지를 숫자 키패드와 양손 SVG 애니메이션으로 익히는 단일 파일 웹앱입니다. 자유 연주, 퀴즈, 멜로디 모드를 제공하며 외부 라이브러리·폰트·이미지를 포함하지 않습니다. 정적 소스 검사상 외부 네트워크 요청 진입점도 0개입니다.

## 실행 방법

1. `clarinet_solfege_trainer.html`을 더블클릭하거나 브라우저의 파일 열기로 엽니다.
2. 주소가 `file:///.../clarinet_solfege_trainer.html` 형태여도 별도 서버 없이 동작하도록 설계되어 있습니다.
3. 소리가 켜져 있을 때는 브라우저 오디오 정책상 첫 버튼 탭이나 키 입력 후 소리가 시작될 수 있습니다.

비공개 온라인 버전은 [클라리넷 운지 트레이너](https://clarinet-fingering-trainer.augustrushkim.chatgpt.site)에서 실행할 수 있으며 소유자 계정 로그인이 필요합니다.

배포와 수업 시연에는 `clarinet_solfege_trainer.html` 한 파일만 필요합니다. 테스트와 README는 개발·검증용이며 앱 실행에 필요하지 않습니다.

일부 `file://` 환경은 localStorage를 차단하거나 파일별로 격리합니다. 이 경우 앱은 오류를 표시하지 않고 현재 세션 메모리로 폴백하며, 브라우저를 닫으면 설정이나 퀴즈 진행도가 유지되지 않을 수 있습니다.

## 고품질 클라리넷 합성음

음원은 외부 샘플이나 네트워크 요청 없이 브라우저의 Web Audio 노드만으로 실시간 생성합니다.

- 샬뤼모·목음역·클라리온·알티시모마다 짝수/홀수 배음 비율, 밝기, 어택, 릴리스와 출력 레벨을 다르게 적용합니다.
- 대역 제한된 어두운/밝은 `PeriodicWave` 두 층을 섞고, 밝은 배음이 조금 늦게 자라도록 해 리드 발음의 과도음을 재현합니다.
- 하나의 결정적 노이즈 소스를 두 필터로 나눠 지속 호흡과 짧은 텅잉/리드 어택을 만듭니다.
- 관 공명 EQ, 저역·고역 보호 필터, 짧은 알고리즘 룸 응답과 마스터 압축기로 피로감과 클리핑을 줄입니다.
- 기본 음정에는 과한 비브라토 대신 ±1.35센트의 매우 느린 흔들림만 적용해 음정 학습을 방해하지 않습니다.
- 단선율 악기 계약을 유지하며 새 음은 이전 음을 60ms 교차감쇠합니다. 모든 오실레이터·노이즈·변조 노드는 릴리스 뒤 정지·해제됩니다.
- B♭ 클라리넷은 기보음보다 장2도 아래, A 클라리넷은 단3도 아래의 실음을 재생하며 설정에서 기보음 재생으로 바꿀 수 있습니다.

## 기본 조작

- 숫자 `1–7`은 현재 옥타브와 변화표 문맥에서 도·레·미·파·솔·라·시를 선택합니다.
- `↑`/`↓`는 옥타브를 바꿉니다.
- `+`/`-`는 변화표 문맥을 바꿉니다.
- 화면의 `[낮은 계이름 C4]`, `[높은 계이름 C5]`, `[반음 C4/C5]` 버튼은 숫자 키의 빠른 입력 문맥을 바꾸며, 버튼만 눌렀을 때 현재 음이나 운지는 바뀌지 않습니다.
- 현재 음에 대체 운지가 있으면 `[기본/대체]`로 두 운지 사이의 손가락 차이 애니메이션을 볼 수 있습니다.

## 단축키 전체 매핑

단축키는 상단 숫자열의 물리 키 `Digit1–Digit7`을 기준으로 합니다. 숫자패드 `Numpad1–7`은 지원 대상이 아닙니다.

| 숫자 | `Control+숫자` 낮은 계이름 | `Shift+숫자` 높은 계이름 | `Alt+숫자`, C4 밴드 | `Alt+숫자`, C5 밴드 |
|---:|---|---|---|---|
| 1 | 도4 · C4 · MIDI 60 | 도5 · C5 · MIDI 72 | 도♯4/레♭4 · C♯4 · MIDI 61 | 도♯5/레♭5 · C♯5 · MIDI 73 |
| 2 | 레4 · D4 · MIDI 62 | 레5 · D5 · MIDI 74 | 레♯4/미♭4 · D♯4 · MIDI 63 | 레♯5/미♭5 · D♯5 · MIDI 75 |
| 3 | 미4 · E4 · MIDI 64 | 미5 · E5 · MIDI 76 | 비활성: 미♯4=파4 토스트 | 비활성: 미♯5=파5 토스트 |
| 4 | 파4 · F4 · MIDI 65 | 파5 · F5 · MIDI 77 | 파♯4/솔♭4 · F♯4 · MIDI 66 | 파♯5/솔♭5 · F♯5 · MIDI 78 |
| 5 | 솔4 · G4 · MIDI 67 | 솔5 · G5 · MIDI 79 | 솔♯4/라♭4 · G♯4 · MIDI 68 | 솔♯5/라♭5 · G♯5 · MIDI 80 |
| 6 | 라4 · A4 · MIDI 69 | 라5 · A5 · MIDI 81 | 라♯4/시♭4 · A♯4 · MIDI 70 | 라♯5/시♭5 · A♯5 · MIDI 82 |
| 7 | 시4 · B4 · MIDI 71 | 시5 · B5 · MIDI 83 | 비활성: 시♯4=도5 토스트 | 비활성: 시♯5=도6 토스트 |

반음 밴드는 마지막으로 선택한 낮은/높은 그룹을 따릅니다.

- 낮은 계이름 버튼 또는 `Control+1–7`을 사용하면 반음 밴드는 C4가 됩니다.
- 높은 계이름 버튼 또는 `Shift+1–7`을 사용하면 반음 밴드는 C5가 됩니다.
- 전체 키패드에서 옥타브 4 또는 5를 직접 고르면 반음 밴드도 해당 값으로 바뀝니다.
- 옥타브 3 또는 6을 선택해도 마지막 C4/C5 반음 밴드는 유지됩니다.
- `Alt+3`과 `Alt+7`은 다른 음으로 자동 이동하지 않으며 현재 음·운지·URL·사운드를 바꾸지 않고 동등음 안내만 표시합니다.
- Ctrl/Shift/Alt 중 정확히 하나만 누른 조합을 처리합니다. Meta, AltGraph, 복수 보조키, IME 조합 중 입력, 입력 폼 편집 중 단축키는 무시합니다.

### 브라우저 예약키 제한

Chrome과 Edge를 포함한 일부 브라우저는 `Control+1–7`을 탭 이동에 예약합니다. 브라우저가 페이지로 키 이벤트를 전달하지 않으면 앱의 `preventDefault()`로 가로챌 수 없습니다. 합성 KeyboardEvent 자동 테스트의 성공은 물리 키보드에서 이 조합이 수신된다는 증거가 아닙니다.

단축키가 전달되지 않는 환경에서는 다음 폴백을 사용합니다.

1. 화면에서 `[낮은 계이름 C4]` 또는 `[높은 계이름 C5]`를 선택합니다.
2. 화면 숫자 버튼을 탭하거나 보조키 없는 일반 숫자 `1–7`을 누릅니다.
3. 변화음은 화면의 `[반음 C4/C5]`를 선택한 뒤 숫자 `1·2·4·5·6`을 사용합니다.

## 학습 모드

### 자유 연주

기본 모드입니다. 옥타브, 변화표, 빠른 분류, 숫자 버튼으로 E3–A6의 42음을 선택합니다. 음을 바꾸면 이전 운지와 새 운지의 차이만 PRESS·RELEASE·SLIDE·HOLD 애니메이션으로 표시합니다. 자유 모드에서 퀴즈나 멜로디로 이동했다가 돌아오면 이탈 전 음과 기본/대체 운지 문맥을 복원합니다.

### 퀴즈

1. 은행을 선택합니다: 낮은 계이름 7음, 높은 계이름 7음, 변화음 10음, 전체 24음, 전체 42음.
2. 한 세션은 10문제입니다. 화면 키패드, 빠른 분류 버튼, 전달 가능한 물리 단축키로 답합니다.
3. MIDI가 같으면 도♯/레♭처럼 표기가 달라도 정답입니다.
4. 첫 오답은 다시 시도하며, 두 번째 오답 뒤에는 정답 운지와 음을 공개합니다.
5. `[듣기]`는 정답 소리만 재생하고 운지를 미리 보여 주지 않습니다.
6. 완료 화면에서 다시 하기, 현재 세션의 틀린 문제만 다시 하기, 자유 모드 복귀를 선택할 수 있습니다.

진행도는 10문제를 끝낸 세션만 누적합니다. 중간에 모드를 이탈한 세션은 저장하지 않습니다.

### 멜로디

내장 곡은 `비행기`, `반짝반짝 작은 별`, `나비야` 세 곡입니다. 선율이 퍼블릭 도메인인 동요의 숫자보만 포함하며 가사는 포함하지 않습니다.

- 곡과 BPM 60–140을 선택한 뒤 재생/일시정지를 누릅니다.
- 이전/다음으로 한 음씩 운지를 관찰할 수 있습니다.
- 숫자보 칩을 누르면 해당 위치로 점프해 음과 운지를 재생합니다.
- 자동 재생 중 키패드나 단축키로 수동 입력하면 먼저 일시정지한 뒤 입력을 처리합니다.
- 소리가 꺼져 있어도 시각적 자동 재생은 계속 동작합니다.
- 곡 끝에서는 자동 정지하며 반복 재생은 현재 버전에 없습니다.

`나비야` 숫자보는 초안이며 강사 감수가 아직 완료되지 않았습니다. 감수 상태: **미완**.

## 설정과 저장 데이터

### 설정

localStorage 키:

```text
clarinet-fingering-settings
```

저장 대상은 악기(B♭/A), 표기 모드, 소리 켬/끔, 실음/기보음 재생, 손 가이드, 손가락 라벨, 애니메이션 속도, 테마(auto/light/dark)입니다. URL 해시의 `instrument` 값은 공유 링크 재현을 위해 저장 설정보다 우선합니다.

### 퀴즈 진행도

localStorage 키:

```text
clarinet-fingering-progress
```

버전 1의 개념적 구조:

```js
{
  version: 1,
  quiz: {
    total: 0,
    correct: 0,
    byMidi: {
      "60": { asked: 3, correct: 2 }
    }
  }
}
```

### URL 공유

예:

```text
#note=Fs4&instrument=Bb&alt=1
#mode=quiz&bank=low
#mode=melody&song=airplane
```

자유 모드는 선택 음을 해시에 기록합니다. 퀴즈는 정답 스포일러 방지, 멜로디는 곡 위치 중심의 상태 관리를 위해 재생 중 `note` 파라미터를 갱신하지 않습니다.

## 데이터 출처와 변경 정책

운지와 키 좌표의 단일 기준은 다음 파일입니다.

```text
01 Source/clarinet_standard_fingering_chart.html
```

앱은 원본의 `COMPONENTS`, `ROUND_IDS`, `HORIZONTAL_IDS`, `DATA`, `REGISTER`를 프로그램으로 추출한 결과를 사용합니다. `01 Source/` 전체는 읽기 전용이며 다음 원칙을 지킵니다.

- DATA 42음의 순서와 MIDI 52–93 연속성을 바꾸지 않습니다.
- 기본 운지 42개와 대체 운지 19개의 키 배열을 다시 입력하거나 임의 수정하지 않습니다.
- 샤프와 플랫 이명동음을 별도 운지로 복제하지 않습니다.
- 키 2→왼손 검지(L1), 키 19→오른손 중지(R2), 키 24의 연동 예외를 유지합니다.
- 직접 누르는 키와 기계적으로 연동되는 키 12·24를 시각적으로 구분합니다.
- 외부 운지표나 추정값으로 원본을 덮어쓰지 않습니다.

## 접근성

- 주요 컨트롤은 native button/select/range를 사용하며 터치 타깃은 최소 44px입니다.
- 현재 모드와 세그먼트에는 `aria-pressed`, 멜로디 현재 음에는 `aria-current`를 제공합니다.
- 키보드 단축키는 화면 도움말과 `aria-keyshortcuts`로 함께 안내합니다.
- 문제, 정오답, 곡 시작·정지·완료는 필요한 범위에서 polite live region으로 알립니다. 자동 재생 중에는 음마다 반복 낭독하지 않습니다.
- 선택, 정오답, direct/linked 키를 색만으로 표현하지 않고 외곽선·점선·텍스트·기호를 함께 사용합니다.
- `prefers-reduced-motion: reduce`에서는 손가락 전환과 셰이크를 즉시 상태 변경으로 대체하지만 퀴즈와 멜로디 기능은 유지합니다.
- 포커스 링과 320/360px 모바일 레이아웃, iOS safe-area/100dvh 폴백을 고려했습니다.

실제 스크린리더 조합과 흑백 출력 판독은 아래 실기 매트릭스와 같이 아직 하드웨어/브라우저 실측이 필요합니다. 최종 색상 토큰의 대비 계산값은 아래 다크 모드 절에 기록했습니다.

입력 수치는 같은 JavaScript 작업 안에서 애니메이터가 예약되기까지의 값이며 첫 픽셀 표시 시간은 아닙니다. 멜로디 수치는 절대 마감 시각 보정 스케줄러의 한 곡 실행 중 최대 단계 오차이므로, 1분 누적 드리프트와 중급 Android 60fps는 별도 실기 확인이 필요합니다.

## 알려진 제한과 남은 검증

- Chrome/Edge 등에서 `Control+1–7`이 브라우저 탭 이동에 가로채질 수 있습니다. 화면 컨트롤과 일반 숫자 키가 공식 폴백입니다.
- 실제 모바일 오디오 unlock과 무음 모드 동작은 기기별 확인이 필요합니다.
- `나비야` 숫자보는 강사 감수 전 초안입니다.
- 멜로디 반복 재생은 현재 버전에 없으며 곡 끝에서 정지합니다.
- 중급 Android의 실제 60fps와 입력 첫 페인트 지연은 측정해야 합니다.
- 일부 `file://` 브라우저 환경에서는 localStorage가 세션 한정으로 폴백할 수 있습니다.
- 이 검증 세션에서는 자동화 보안 정책이 `file://` 탐색을 차단해 더블클릭 실행을 실제 브라우저로 확인하지 못했습니다. 단일 파일 구조와 세션 메모리 폴백은 정적·로컬 HTTP로 검증했습니다.
